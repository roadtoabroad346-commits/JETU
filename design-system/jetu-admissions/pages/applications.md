# Application CRM workspace — Phase 18

Use the JETU master blue/yellow/navy/ice tokens and system type. Hierarchy is
portfolio metrics → filters and create action → board/list → owned application
workspace with stage, verified target facts, readiness, notes, scholarships and
append-only history. “Submitted” always expands to “externally submitted,
user-confirmed”; the official portal is an external destination, never a JETU
submission control.

Mobile is one column with wrapping filters and explicit stage buttons. Board
columns may scroll horizontally inside their labeled region without creating
page overflow. All drag-equivalent movement is available through visible buttons
and keyboard controls. Status uses text plus shape/color. Forms retain values,
show inline errors and disable only while a real request is pending. Motion is
limited to existing feedback/card tokens and is removed for reduced motion.

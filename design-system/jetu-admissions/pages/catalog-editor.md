# Catalog editorial console

Reuse MASTER.md and existing JETU form/panel patterns. Source-first hierarchy:
record snapshot → parent dependencies → exact claims and official sources →
review note/attestation → publication → immutable before/after audit history.
No automatic verification badge and no bulk approval. Claim verification and
whole-record publication are separate actions.

All writes require reviewer membership, notes, explicit human attestation and
current versions. Read-only editors see the same evidence without write controls.
Keep source text escaped, links HTTPS/new-tab with noopener, and raw structured
catalog fields readable in native details. Status and errors use words, not color
alone. Responsive cards and wrapped controls work at 375px; native details,
checkboxes, labels and textarea support keyboard users. Preserve notes on failed
writes. Pending controls must prevent duplicate actions. Existing tokens/fonts,
44px controls and reduced-motion defaults remain authoritative.

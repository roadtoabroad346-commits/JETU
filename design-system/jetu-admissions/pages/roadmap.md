# Roadmap workspace — Phase 17

Use JETU blue/yellow/navy/ice tokens and the system font. One panel controls enrollment year, timezone, weekly availability and saved published targets. The hierarchy is settings → progress and next action → overview/Kanban/timeline/calendar/checklist → task detail. A profile-only state works before any target is published.

Task cards show status, priority, due date and origin. Detail separates official deadline, internal recommendation and student override. Unknown dates are labeled. Kanban uses explicit status controls. Mobile layout wraps controls, allows scrolling inside the board/calendar and keeps 44px targets. Reduced motion disables hover transitions. Writes show persisted outcome or error feedback.

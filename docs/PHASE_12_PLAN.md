# Phase 12 plan and decision record

Objective: a public read-only University & Program Explorer over the canonical admissions catalog, with URL-backed filters, stable pagination, canonical detail links, official provenance and an honest empty/unavailable state. No real reviewed university records exist yet.

Prerequisites discovered after plan: the authorized Jetuu development database has Phase 08–10 migrations that were absent from this Git checkout and origin/main. Their exact migration statements were recovered from `supabase_migrations.schema_migrations` into matching local filenames. Git history still ends at Phase 06. No prior phase is upgraded to VERIFIED by this recovery. Phase 11 ingestion/review UI is absent.

Implementation boundary: add only `public.catalog_search(jsonb)` over existing `catalog_entities`, `institutions`, `degree_programs`, campus, taxonomy, tuition, intake, deadline and funding tables. Run as SECURITY INVOKER under existing RLS. Require published/verified entity visibility plus verified source claims for institution and program. Grant only EXECUTE to anon/authenticated; no new tables, privileged browser keys, production fixtures or new write paths. A server-only REST adapter uses the publishable key and no-store fetch. A failed/unconfigured backend has a localized unavailable state. Use existing JETU blue/yellow tokens and RU/KK/EN navigation; GET forms preserve search state through URL/reload/history.

API: `GET /api/catalog/universities` validates search inputs then calls the same RPC; sanitized `{data,requestId}` or error response. Search accepts q, country ISO2, city, level, major, language, mode, exam, intake, deadline, maxTuition+currency, funding, sort and page. SQL caps result page size at 24 and offset at 2400; the app uses 12 per page. Program detail reads existing normalized requirements, intake deadlines and scholarship links. Unsupported ranking, save, compare and planning controls are withheld until their data/auth modules exist.

Acceptance: transactionally prove published record visibility, draft isolation and representative filters against synthetic fixture data; no fixture remains. Run format/lint/strict TS/unit/build, browser/axe at mobile and desktop, and source/grant advisors. Relevant external blockers: container registry denies local PostgreSQL image, and this workspace's direct Supabase REST tunnel returns 403. Because real reviewed records and runtime read-path verification are absent, Phase 12 remains PARTIAL.

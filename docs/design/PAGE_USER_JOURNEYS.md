# Phase 04 journey

Open home → read the preparation status → switch language → reload/back/forward
while retaining locale → recover from a nonexistent link through a real home link.
No onboarding, application, payment or AI journey is publicly presented as available.
Those journeys must be implemented and persisted in their designated phases.

## Phase 05 component journey

Open /{locale}/design-system → inspect shared brand/tokens → select feedback states →
validate a local typography preview → navigate tabs/dialog/help by keyboard → filter /
sort actual library entries → search a component and focus its section → switch
locale or return to existing home. Nothing is saved/sent; reload resets previews.
